Calcus Ai — Colombo

The complete website source is in dist.

To preview locally: open a terminal in this project folder and run python3 -m http.server 8000 --directory dist (Windows: py -m http.server 8000 --directory dist). Open http://localhost:8000 in your browser.

Edit dist/index.html for layout and themes. Edit dist/eyes.js for mouse-following eyes. Face artwork and font files are included. The Colombo background loads from Unsplash and requires internet access.

.openai/hosting.json identifies the existing Sites project and contains no credentials.

White mode uses the bundled colombo-day.jpg photo by Manorie Kodithuwakku on Unsplash: https://unsplash.com/photos/6iqB-y0EBCw (Unsplash License).
